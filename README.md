# VPS Sales Website

一个现代化的VPS云服务器售卖网页，采用响应式设计，支持多种套餐展示和用户交互。

## 🚀 功能特性

- ✨ **现代化设计** - 渐变背景和卡片悬停效果
- 📱 **响应式布局** - 适配手机和桌面设备
- 💰 **多套餐展示** - 基础型、标准型、高级型、企业型
- 🛒 **交互功能** - 购买按钮和购物车通知
- 🎨 **纯前端实现** - 无需后端依赖

## 📋 套餐配置

## 🛠️ 技术栈

- **HTML5** - 语义化结构
- **CSS3** - 现代化样式和动画
- **JavaScript** - 交互功能
- **Grid & Flexbox** - 响应式布局

## 🚀 快速开始

1. **克隆仓库**
   ```bash
   git clone https://github.com/your-username/vps-sales-website.git
   ```

2. **本地运行**
   ```bash
   cd vps-sales-website
   # 用浏览器打开 index.html
   open index.html
   ```

3. **部署上线**
   - 上传到任意Web服务器
   - 或使用GitHub Pages
